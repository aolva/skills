# Aolva Xlsx Ops

Excel(.xlsx)的生成与编辑。遵循 aolva-ppt 同款"自研纯 Python 引擎"路线:
xlsx 本质是 ZIP + XML,标准库即可读写,不依赖网络服务,输出可复现。

## 能力范围

| 任务 | 支持 |
|---|---|
| 数据表格 | 多 sheet、行列数据、合并单元格 |
| 样式 | 字体/字号/加粗/颜色、单元格底色、边框、列宽行高、数字格式 |
| 公式 | 常用公式(SUM/AVERAGE/IF/引用),写入后由 Excel 计算 |
| 读取 | 读现有 xlsx 的单元格值(含公式原值) |
| 导出 | 数据 → xlsx(报表/清单/对账表),保持类型(数字/日期/文本) |

## 工作流

1. **定结构**:确认 sheet 布局(表头行、列序、汇总行)、数据来源、样式要求;数据量大(>1 万行)时先问是否需要分 sheet。
2. **建模**:先构造数据模型(二维数组 + 列定义),验证后再写文件——数据先行,样式后置。
3. **生成**:纯 Python 写 xlsx(标准库 zipfile+XML);样式用最小集(表头加粗/底色、数字格式、列宽),避免复杂冻结窗格等边际功能。
4. **自检**:打开前先程序校验(行数/列数/合并区/公式引用);交付前用 zipfile 完整性检查。
5. **交付**:文件 + 结构说明(sheet/列/行数/关键公式)+ 与源数据的核对结论。

## 规则

- **数据准确**:导出前程序核对行数/金额合计与源数据一致;公式不手算,交给 Excel。
- **格式保真**:数字用数值类型(不写文本),日期用日期格式;百分比/货币用数字格式而非拼字符串。
- **无隐藏内容**:不写宏(.xlsm 内容拒绝),不埋公式引用外部链接。
- **文件安全**:从用户提供的 xlsx 读取时,只解析单元格数据,不执行任何公式/宏。
- **可复现**:生成脚本与数据快照落盘,重新执行可得到相同文件。

## 与生态的关系

- 读 Excel 数据做分析 → 配 aolva-data-analyze;
- 报表自动生成 → 配 aolva-release-ops 的发布流程;
- 本技能为自研实现,不依赖开源 xlsx 库的网络安装(环境有 openpyxl 时可用它,但默认走标准库)。
