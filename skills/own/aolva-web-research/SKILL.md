# Aolva Web Research

面向调研类任务的网页研究方法论:不满足于单源结论,要求证据链。

## 工作流

1. **拆解问题**:把研究问题拆成 3-7 个子问题,每个子问题对应可回答的检索目标。
2. **多源检索**:每个子问题至少 2 个独立来源(官网/官方文档、行业报告、一手数据、社区讨论);优先一手来源。
3. **抓取与笔记**:抓取后立即做结构化笔记——URL、发布机构、日期、关键事实(逐条引用原文)、可信度评级。
4. **交叉验证**:关键事实必须≥2 个独立来源一致才标"确认";不一致标"存疑"并列出分歧。
5. **成稿**:输出结构化报告:

   ```text
   # 标题
   ## 结论先行(3-5 条,每条带来源编号)
   ## 证据
   | # | 事实 | 来源 | 日期 | 可信度 |
   ## 分歧与不确定性
   ## 下一步(可继续深挖的问题)
   ```

## 质量规则

- **标注每一处事实**:报告中每个断言后跟 `[S1]` 等来源编号,文末附来源清单(标题+URL+日期)。
- **区分事实/推断/建议**:推断和建议明确标注,不与事实混排。
- **时效性**:日期敏感的结论标注"截至 YYYY-MM-DD";检索时优先近 12 个月来源。
- **可疑内容**:来源可信度低(个人博客/匿名/营销软文)时降级使用并说明。
- **不确定就说不确定**:检索不到的高确定性答案,写"未找到权威来源",禁止编造。

## 输出形态

默认产出 Markdown 报告文件(落到工作目录 `research/` 下);用户要求时同步产出对照表或一页速览。
