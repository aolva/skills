# Aolva Image Ops

平台统一的图像能力入口。生成走 ai-gateway 多模态档位(见 aolva-llm-gateway),
轻量编辑(裁剪/缩放/叠加)走本地(见 aolva-local-compute)。目标是**每次出图可复检、可迭代**。

## 能力分工

| 任务 | 路径 |
|---|---|
| 文生图/图生图/风格化 | ai-gateway 多模态档位 |
| 裁剪/缩放/格式转换/拼图 | 本地(Pillow 等,轻量) |
| 批量生成 | 本地批量 + 网关档位说明(先报数量与成本) |
| 视觉质检 | 走 aolva-eval-qa 的视觉质检流程 |

## 提示词规范(结构化五要素)

1. **主体**:谁/什么(具体名词,避免"一个好看的…");
2. **场景与构图**:环境/视角/镜头(特写/全景/俯拍);
3. **风格**:明确风格词(写实/扁平/3D/插画/某设计语言),或引用参考图;
4. **色彩与光线**:主色调/明暗/氛围;
5. **负向提示**:禁止出现的元素(文字、水印、畸形)。

## 工作流

1. **定用途**:配图(文章/PPT/营销)还是功能图(截图/图表/头像)?用途决定规格(尺寸/比例/风格)。
2. **写提示词**:按五要素结构化;用户给参考图时以参考图为准做风格迁移。
3. **生成**:记录模型档位与提示词版本(可复现);一次生成 2-4 个候选供选择。
4. **编辑与后处理**:本地完成尺寸/格式/压缩;导出规格(web 用 JPEG/WebP,打印用 PNG)。
5. **质检**:视觉核对(变形/文字乱码/主体完整);批量任务抽检 ≥20%。
6. **交付**:成品 + 提示词与参数记录 + 源图路径;文档用途给 alt/文件名规范。

## 规则

- **版权边界**:不生成真人肖像的冒充、品牌 logo 的直接复制、受保护角色的商用;生成物默认按平台内容政策使用。
- **提示词可复现**:每次生成记录完整提示词与档位;迭代时保留版本差异说明。
- **成本透明**:批量生成先报数量与预估成本(网关口径),同意后执行。
- **配图不喧宾夺主**:正文配图优先与内容直接相关;装饰性图片少用。
