# Aolva Audio Ops

音频能力入口:配音/旁白、音频剪辑与格式处理。TTS 走平台可用能力(ai-gateway 或本地算力,
见 aolva-local-compute),剪辑处理走本地工具(ffmpeg 等)。

## 能力分工

| 任务 | 路径 |
|---|---|
| 文本转语音(旁白/配音) | 平台 TTS 能力(网关)或本地模型 |
| 剪辑(裁剪/拼接/音量/淡入淡出) | 本地 ffmpeg |
| 格式转换/降噪/采样率 | 本地 ffmpeg |
| 音频 + 视频合成 | 配 aolva-release-ops 或视频相关技能 |

## 工作流

1. **定需求**:用途(PPT 旁白/营销视频/演示)、语言与口吻(正式/活泼)、时长约束、输出格式。
2. **写脚本**:旁白脚本按"每句可独立成音"组织;标注停顿/重音;脚本给用户确认后再合成(改稿成本高)。
3. **合成**:按脚本分段生成,记录每段参数(语音/语速/音调/模型);分段便于局部重录。
4. **剪辑**:拼接 + 首尾淡入淡出 + 音量归一;背景音乐(如有)人声压低(ducking)。
5. **质检**:试听关键段落(语速/断句/错字);时长核对;批量生成抽检 ≥30%。
6. **交付**:成品音频 + 脚本与分段清单(便于局部修改)+ 参数记录。

## 规则

- **脚本先行**:先出旁白脚本给用户确认,再合成;禁止直接合成后大改。
- **口音与语气**:中文配音注意多音字/专业名词读音,拿不准的先标出并确认。
- **音质底线**:采样率 44.1k 以上;音量不过载;不要奇怪的口音模仿。
- **版权**:背景音乐用免版权素材或用户授权素材;不商用未授权音乐。
- **成本透明**:批量/长文本 TTS 先报数量与成本(网关口径);本地模型优先(成本低)。

## 交付

`audio/<任务名>/`:成品 + 分段音频 + 脚本.md + 参数清单;旁白工程保留可重录结构。
