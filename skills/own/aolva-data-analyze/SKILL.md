# Aolva Data Analyze

面向结构化数据(CSV/JSON/Excel/SQL 导出)的探索式分析流程。目标是**可复核的结论**而非玄学洞察。

## 工作流

1. **摸底**:数据规模(行列数)、字段类型、缺失率、脏数据(空串/异常值/重复行);先打印样本(前 5 行 + schema)。
2. **定问题**:与用户确认分析目标(描述性/对比/趋势/异常发现);未明确时给 2-3 个建议方向让用户选。
3. **清洗**:缺失处理策略(丢弃/填充/标记,说明理由)、类型校正、去重;清洗动作可复现(脚本化)。
4. **分析**:
   - 描述:均值/中位数/分位数/分布形态;
   - 对比:分组对比(按类目/时间/版本),说明样本量;
   - 趋势:时间序列的环比/同比/滚动均值;
   - 异常:z-score / IQR 初步圈定,再人工研判。
5. **结论**:每个结论配一个可复核的数字或图表;标注置信与局限(样本量小、口径问题)。

## 规则

- **用代码跑,不口算**:所有数字用 python 脚本计算,关键结果打印中间过程;禁止凭印象报数。
- **因果与相关分离**:发现相关性时只说"相关",不做因果断言。
- **口径先行**:同比/占比等必须先定义口径(分母是什么、时间边界)。
- **可视化**:图表必须带标题、轴标签、单位;双指标对比用同尺度或说明尺度差异;优先 matplotlib/内置能力,不引额外依赖。
- **数据安全**:数据集含个人信息时,输出匿名化;不把原始数据贴进无关输出。

## 交付

分析报告(结论先行 + 方法 + 数字证据 + 图表),脚本与清洗日志落盘(工作目录 `analysis/`),可重复执行。
