# Aolva Doc QA

面向业务文档(合同、报告、发票、论文、表格)的理解与转换。文档智能是 Nurbell
产品线的核心能力,本技能定义 agent 处理文档的统一流程。

## 能力分层(按可用工具自适应)

1. **文本型文档**(可复制文字):直接读取/抽取,不依赖 OCR。
2. **扫描/图片型文档**:优先用可用 OCR 能力(如 skills/extension/mineru 或 Nurbell 文档智能服务);无 OCR 工具时明确告知用户"无法可靠识别",不硬猜。
3. **表格型**:抽取时保留行列结构(CSV/Markdown 表格),不压成流水文本。

## 工作流

1. **定目标**:用户要"抽取/问答/摘要/转换"哪种?抽取范围是全文档还是指定章节?
2. **摸底**:文档类型、页数、语言、结构(章节/表格/页眉页脚/水印)。
3. **抽取**:按目标提取;数值/日期/金额原样保留并标注出处(页码/章节)。
4. **问答**:答案必须带出处(页码/段落引用);无答案时明说"文档中未找到",禁止编造。
5. **转换**:输出格式与源文档一致(表格→表格);转换后自检关键内容无丢失。

## 质量规则

- **出处必标**:任何从文档得出的结论都附页码或章节定位。
- **数字准确**:金额/比例/日期逐字符核对;小数点、千分位、货币单位不丢。
- **区分原文与解读**:引用原文用引号;解读性内容标注"据此推断"。
- **敏感信息**:身份证/手机号/银行账号等按用户指示处理(默认打码),不扩散到无关输出。
- **超长文档**:分批读入(按章节),先建目录索引再定点读取,不整篇硬塞上下文。

## 输出

- 抽取:结构化清单(Markdown 表格或 JSON,按用户偏好)。
- 问答:答案 + 出处。
- 摘要:分层摘要(一段话 + 要点 + 关键数据表)。
- 转换:目标格式文件,并附"转换自检清单"(页数/章节数/关键字段是否齐)。
