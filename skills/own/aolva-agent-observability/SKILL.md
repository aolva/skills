# Aolva Agent Observability

门卫 AI / Aolva Studio / 各 agent 任务的运行观测。口径统一来自 ai-gateway 计量
与算力路由(NewAPI)计量,目标是**每一次调用可归因、每一笔成本有出处**。

## 观测维度

| 维度 | 数据来源 |
|---|---|
| 调用量 | ai-gateway 计量(模型/档位/请求数) |
| 成本 | 网关单价 × 用量;算力走路由计量口径 |
| 质量 | 完成率、重试率、超时率(结合 aolva-eval-qa 的评测) |
| 归因 | 按任务(项目/会话)、按技能、按模型档位分组 |

## 工作流

1. **定窗口与口径**:确认统计时间段与分组维度(按任务/技能/模型);确认单价口径(网关计量为准)。
2. **取数**:从网关计量接口/日志取原始数据;算力部分从路由计量取;不混用两套口径。
3. **聚合**:分组汇总(token/请求/成本/延迟均值/错误率);异常点(成本突增/延迟尖峰)单独标注。
4. **归因**:成本最高的任务/技能/档位排序,给出占比;找出"成本高价值低"的调用(如大模型档跑小任务)。
5. **建议**:优化点(降档/缓存/批量化/本地算力分流,见 aolva-local-compute)附数量级估算。
6. **交付**:报告(总览 → 分组明细 → 异常 → 建议),原始数据可复查。

## 规则

- **口径一致**:网关计量与供应商账单不一致时,以网关为准并标注差异;不静默合并。
- **不泄露数据**:会话内容/用户输入不进报告;只出聚合口径。
- **成本敏感**:批量拉取大数据窗口先问用户;估算结论标"估算"。
- **敏感归因**:定位到具体用户/项目的成本时,报告脱敏(仅内部可见时保留,输出前确认)。

## 交付

`observability/<日期>/`:聚合报告 + 明细 CSV + 原始数据路径。支持按需周报/月报模板复用。
