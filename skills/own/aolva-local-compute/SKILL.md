# Aolva Local Compute

平台规划了本地算力中心(MacBook Pro 128G,见 `Platform/Docs` 的本地算力规划)。
本技能规范 agent 使用本地算力的流程:能本地跑的不上云,成本可控、可离线。

## 适用判定

| 任务 | 建议 |
|---|---|
| 长文本 embedding / 向量化 | 本地(批量、便宜) |
| 小模型推理(分类/抽取/短生成) | 本地(单次请求优先本地) |
| 大模型复杂推理/多模态 | 网关(ai-gateway,见 aolva-llm-gateway) |
| 批处理/离线任务 | 本地 + 队列化 |
| 不确定 | 问用户:要成本优先还是质量优先 |

## 工作流

1. **探测环境**:检查本地推理环境(ollama / mlx / 已装模型清单);未安装时说明安装方案并询问。
2. **选模型**:按任务档位选已装模型;本地没有合适模型时,告知"需先下载 X GB",征得同意后执行。
3. **跑任务**:
   - 单发:直接调用;记录耗时与结果。
   - 批量:分批 + 进度输出 + 断点续跑(结果落盘,失败重试有限次)。
4. **质量校验**:本地小模型输出抽检(尤其结构化 JSON);异常率高的任务建议升级到网关档位并说明原因。
5. **资源意识**:128G 内存但 GPU 有限;大并发任务排队,避免内存打爆;任务结束清理大中间文件。

## 规则

- 本地与云端结果口径不一致时(embedding 维度/模型版本),向用户明示差异。
- 模型文件/缓存路径统一放约定目录,不散落工作目录。
- 涉及"本地 vs 云端"成本对比时,给出数量级估算(耗时×单价口径)。
